# Tank Decoration 20 Prompt Set

Goal: create 20 additional tank decoration assets for Coral Haven. These are draggable/placeable tank objects, so each asset must read clearly at small mobile size, have a bottom-safe anchor, and avoid covering too much of the tank.

Generation format:

- Source size: `512x512` PNG.
- Source background: pure solid flat magenta `#ff00ff`.
- Final runtime later: keyed transparent `160x160` PNG under `public/assets/decorations/`.
- Generate one object per image, not a sheet.

## Shared Style Lock

Paste this exact style lock into every individual generation prompt:

> Style lock: create a single isolated tank decoration sprite for a mobile casual aquarium game, 512x512 PNG on pure solid flat magenta key background `#ff00ff`. Soft toy-like painterly rendering, bright readable silhouette, clean antialiased edge, no drop shadow, no glow blending into the key color, no text, no label, no frame, no contact sheet, no fish, no animals. The object should fit comfortably inside the square with small padding, have a natural bottom anchor for placement on a seabed, and remain readable when resized to 160x160. Avoid busy micro-detail and avoid colors too close to pure magenta on the outer edge.

## Negative Prompt

Use this negative prompt for all decorations:

> no non-magenta background, no checkerboard transparency preview, no text, no UI, no label, no frame, no fish, no animals, no bubbles unless the object is explicitly a bubble object, no full tank scene, no sand floor, no hard black outline, no cast shadow, no huge empty margins, no cropped object, no multiple objects unless described as one grouped decoration.
