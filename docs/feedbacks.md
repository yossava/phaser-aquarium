# Feedback

## Open Feedback

## Resolved Feedback

- Tank should be full screen in portrait mode.
- Store, Care, Album, Goals, and Settings should each be opened from an individual icon.
- Food should work as a toggled tool: activate one food icon, then tap the tank to drop it.
- Sick fish should have an explicit healing path through Medicine.
- Fish sell prices should be higher.
- Sick fish should still produce coins, but only as `+1` drops.
- Coin drops should sink toward the bottom of the tank.
- Sick fish should produce coins slower than healthy fish.
- Fish sell price should increase based on fish attributes.
- Coin drops should sink to the bottom.
- Coin drops should stack only up to 5 uncollected coins until the player collects them.
- Each coin type should have a different color.
- Main menu buttons should be on the right side of the screen.
- Food and medicine buttons should be on the left side of the screen.
- Top statistics should be less crowded on portrait screens.
- Medicine should keep fish healthy for a meaningful recovery window instead of relapsing after seconds.
- Shop should look like an intuitive catalog/grid instead of a debug list.
- Medicine should drop like food and heal only after a fish eats it.
- Medicine should look like a green pill when dropped.
- Fish should show small hunger and mood bars above them.
- Full bars should mean good for both hunger/fullness status and health/mood status.
- Fish and their preferred food should share visual colors.
- Fully grown fish need an obvious visual marker.
- Fish rarity should be visible through star badges.
- Food color mapping should be on the fish tail instead of the overhead indicator.
- Sick fish should keep their color identity, only slightly desaturated.
- Fish should not become hungry too easily.
- Player can rent an Auto Feeder for 1 minute.
- Player can rent an Auto Coin Collector for 1 minute.
- Fish should aggressively run to food if they can still eat more.
- Auto Feeder should drop food at a random position from the top of the tank.
- Coin drops should fall faster than food.
- Player should be able to set how many minutes to rent Auto Feeder and Auto Coin Collector.
- Auto Feeder should decrement food stock when dropping and support each hungry fish species' needed food type.
- Tank fish capacity should be 10.
- Buying fish should add it to the tank automatically without a placement tap.
- Remove fish incompatibility; all fish can be together in one tank.
- Show total wealth statistic.
- Add 50 fish types categorized by tank level.
- Require tank upgrades before higher-level fish can enter the tank.
- Allow lower-level fish in higher-level tanks, but block higher-level fish in lower-level tanks.
- Show a tank indicator when a useful purchase or upgrade is needed.
